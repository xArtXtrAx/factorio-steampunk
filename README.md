# Factorio Steampunk

> **Continuidad del desarrollo con GPT:** leer primero [`CONTINUIDAD_GPT.md`](CONTINUIDAD_GPT.md) desde `main`.

Juego web de gestión y automatización de recursos inspirado en Factorio, con una interfaz deliberadamente simple y un DEV Panel permanente para modificar parámetros de simulación en tiempo real.

## Objetivo inicial

- Resolución de referencia: 1920×1080.
- Área de juego: 2/3 de la ventana.
- DEV Panel: 1/3 de la ventana.
- Retícula inicial: 30×30.
- Recursos iniciales: carbón, cobre, hierro y piedra.
- Extracción manual por click izquierdo.
- Velocidad inicial: 1 recurso/segundo, editable desde el DEV Panel.
- Inventario visible en la parte superior.
- Dirección visual: steampunk con acentos neón y tipografía legible.
